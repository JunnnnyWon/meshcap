# 3D 프린팅 검증 기록

리포트 7장에 들어갈 실측 데이터를 여기에 기록합니다. 표를 채운 뒤 리포트 생성 스크립트가
이 파일을 참조합니다.

## 준비

보정 전후 STL 쌍은 아래 명령으로 만듭니다.

```bash
npm run export:stl     # bench/exports/*_before.stl, *_after.stl
```

실제 Meshy·Tripo 모델은 웹 도구에 넣고 `STL 내려받기`로 보정본을 받은 뒤,
원본도 함께 슬라이서에 올려 비교합니다.

## 측정 항목

같은 모델의 보정 전 파일과 보정 후 파일을 **같은 슬라이서 · 같은 프로파일**로 열고 다음을 기록합니다.

- 슬라이서가 띄운 경고 또는 오류 메시지 (그대로 옮겨 적기)
- 자동 수리 기능이 개입했는지 여부
- 예상 출력 시간
- 소재 사용량 (FDM은 g, SLA는 mL)
- 서포트 부피 비중
- 첫 층 접지 면적
